# سیستم مدیریت رزرو نوبت پزشک

## 🎯 هدف پروژه

ایجاد یک پلتفرم ساده و کاربرپسند برای:
- مدیریت نوبت‌های پزشکی
- ثبت و مدیریت اطلاعات پزشکان
- مدیریت بیماران و کاربران
- زمان‌بندی و برنامه‌ریزی ویزیت

## 🛠️ تکنولوژی‌های استفاده شده

- **Laravel 12**: فریمورک اصلی PHP
- **FilamentPHP v3**: پنل ادمین مدرن و قدرتمند
- **Sqlite**: پایگاه داده
- **Tailwind CSS**: استایل‌دهی (از طریق Filament)
- **Livewire**: تعاملات Real-time

## ✨ ویژگی‌های اصلی

### 1. مدیریت کاربران
- ✅ ثبت نام و ورود کاربران
- ✅ پروفایل کاربری
- ✅ احراز هویت امن

### 2. مدیریت پزشکان
- ✅ ثبت اطلاعات کامل پزشکان
- ✅ تخصص‌ها و مدارک
- ✅ برنامه کاری و ساعات ویزیت
- ✅ تعرفه‌ها و هزینه‌ها

### 3. سیستم رزرو نوبت
- ✅ رزرو آنلاین نوبت
- ✅ انتخاب تاریخ و ساعت
- ✅ مشاهده نوبت‌های فعال
- ✅ لغو و تغییر نوبت
- ✅ تایید/رد نوبت توسط پزشک

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
```bash
- PHP >= 8.2
- Composer
- Node.js & NPM
- Git
```

### مراحل نصب

1. **کلون کردن پروژه**
```bash
git clone https://github.com/yusofsf/DoctoreMan
cd DoctoreMan
```

2. **نصب وابستگی‌های PHP**
```bash
composer install
```

3. **نصب وابستگی‌های JavaScript**
```bash
npm install
npm run build
```

4. **تنظیمات محیطی**
```bash
cp .env.example .env
php artisan key:generate
```

5. **اجرای Migration و Seeder**
```bash
php artisan migrate --seed
```

6. **راه‌اندازی سرور**
```bash
php artisan serve
```

7. **دسترسی به پنل ادمین**
```
http://localhost:8000/panel
```

## 🗄️ مدل‌های دیتابیس

### User (کاربران)
- نام و نام خانوادگی
- ایمیل
- شماره تلفن
- نقش (بیمار، پزشک، ادمین)
- وضعیت فعال/غیرفعال

### Doctor (پزشکان)
- اطلاعات پزشک
- تخصص
- شماره نظام پزشکی
- آدرس مطب
- ساعات کاری
- تعرفه ویزیت

### Patient (بیماران)
- جنسیت
- تاریخ تولد
- شماره موبایل

### Admin (مدیران)
- نام نمایشی
- توضیحات
- وضعیت
- آخرین ip لاگین شده
- آخرین زمان لاگین شده

### Schedule (زمان بندی ها)
- روز هفته
- زمان شروع
- زمان پایان

### َAppointment (رزروها)
- بیمار
- پزشک
- تاریخ
- وضعیت (در انتظار، تایید شده، لغو شده، انجام شده)
- توضیحات
- زمان بندی

## 🎨 ویژگی‌های Filament استفاده شده

### Resources
- **Form Builder**: فرم‌های پیشرفته با اعتبارسنجی
- **Table Builder**: جداول قدرتمند با فیلتر و جستجو
- **Actions**: عملیات سریع روی رکوردها

### Components
- **TextInput**: ورودی متن
- **Select**: انتخاب از لیست
- **DateTimePicker**: انتخاب تاریخ و زمان
- **Toggle**: سوئیچ فعال/غیرفعال
- **RichEditor**: ویرایشگر متن
